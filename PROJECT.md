# Project Summary
Switchboard is a MCP library that hosts multiple MCP servers with a central point of access for customers.

# Requirements
1. Code must be written in Python.
2. The top-level directory of project directory is `switchboard`, not `src`.
3. The application must be containerized.
4. Code and architecture must follow current best practices.
5. Production application must run in cloud but development must be able to run locally for testing.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Direct Connect -> ALB | External customers reach internal ALB via Direct Connect |
| ALB -> Gateway ECS | ALB forwards HTTPS traffic to gateway containers on port 8000 |
| Gateway -> MCP Server | Gateway proxies requests to MCP containers; MCP servers accept traffic only from gateway |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-7-06 | Elevation of Privilege | MCP server lateral movement | mitigate | MCP server security group allows ingress ONLY from gateway SG on port 8000 (D-08); no egress rules needed |
| T-7-07 | Information Disclosure | Unencrypted ALB traffic | mitigate | ALB listener uses HTTPS (port 443) with TLS 1.3 policy `ELBSecurityPolicy-TLS13-1-2-2021-06`; ACM certificate required |
| T-7-08 | Spoofing | DNS cache poisoning in Cloud Map | mitigate | TTL=10 with MULTIVALUE routing and failure_threshold=1 minimizes stale record window |
| T-7-09 | Denial of Service | ALB exposed to all VPC traffic | accept | Internal ALB within private VPC; Direct Connect controls who can reach it; additional WAF is a future enhancement |
</threat_model>

<verification>

- Cloud Map DNS TTL is 10 seconds (not default 60)

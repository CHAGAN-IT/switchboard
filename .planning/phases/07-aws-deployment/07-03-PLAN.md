**Gateway task definition:**
```hcl
resource "aws_ecs_task_definition" "gateway" {
  family                   = "switchboard-gateway"
  requires_compatibilities = ["FARGATE"]
  network_mode             = "awsvpc"
  cpu                      = "256"
  memory                   = "512"
  execution_role_arn       = aws_iam_role.ecs_execution.arn
  task_role_arn            = aws_iam_role.gateway_task.arn

  container_definitions = jsonencode([{
    name  = "gateway"
    image = "${var.ecr_repository_urls["gateway"]}:latest"
    portMappings = [{ containerPort = 8000, protocol = "tcp" }]
    essential = true
    secrets = [
      { name = "CUSTOMER_JWT_SECRET", valueFrom = var.customer_jwt_secret_arn },
      { name = "OPERATOR_JWT_SECRET", valueFrom = var.operator_jwt_secret_arn },
      { name = "DATABASE_URL", valueFrom = var.database_url_secret_arn }
    ]
    environment = [
      { name = "CLOUD_MAP_DOMAIN", value = ".switchboard.local" },
      { name = "AWS_REGION", value = var.aws_region },
      { name = "ECS_CLUSTER_ARN", value = aws_ecs_cluster.main.arn }
    ]
    logConfiguration = {
      logDriver = "awslogs"
      options = {
        "awslogs-group"         = aws_cloudwatch_log_group.gateway.name
        "awslogs-region"        = var.aws_region
        "awslogs-stream-prefix" = "gateway"
      }
    }
    healthCheck = {
      command     = ["CMD-SHELL", "python -c \"import urllib.request; urllib.request.urlopen('http://localhost:8000/.well-known/oauth-protected-resource')\""]
      interval    = 10
      timeout     = 5
      retries     = 3
      startPeriod = 15
    }
  }])
}
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| ECS Agent -> Secrets Manager | Execution role fetches secrets at task start |
| Application -> AWS APIs | Task roles scope runtime AWS API access per service |
| Migration task -> RDS | One-time run-task needs DB connectivity |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

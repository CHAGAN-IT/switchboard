<objective>
Create the foundational Terraform modules for Switchboard AWS infrastructure: state bootstrap, VPC networking with VPC endpoints, RDS PostgreSQL, Secrets Manager placeholders, and ECR repositories.

Purpose: These modules form the base layer that all other infrastructure (ALB, ECS, Cloud Map) depends on. The VPC provides private networking (D-05), RDS provides the database (D-16), Secrets Manager stores credentials (D-19/D-20), and ECR hosts container images (D-21).

Output: Four reusable Terraform modules under `infra/modules/` plus a bootstrap configuration under `infra/bootstrap/`.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Terraform state -> S3 | State file contains resource metadata; stored encrypted at rest |
| VPC boundary | All resources in private subnets; no internet-facing resources |
| RDS network access | Only allowed security groups can reach port 5432 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-7-01 | Information Disclosure | Terraform state in S3 | mitigate | KMS encryption on S3 bucket (bootstrap/main.tf), bucket versioning, public access block with all four settings true |
| T-7-02 | Information Disclosure | RDS data at rest | mitigate | `storage_encrypted = true` on aws_db_instance (rds/main.tf) |
| T-7-03 | Elevation of Privilege | RDS network access | mitigate | Security group with ingress restricted to specific `allowed_security_group_ids` on port 5432 only |
| T-7-04 | Tampering | Container images in ECR | mitigate | `image_tag_mutability = "IMMUTABLE"` and `scan_on_push = true` on all ECR repositories |
| T-7-05 | Information Disclosure | Secrets in Terraform state | mitigate | Create `aws_secretsmanager_secret` only (no `aws_secretsmanager_secret_version`); values populated out of band per D-20 |
</threat_model>

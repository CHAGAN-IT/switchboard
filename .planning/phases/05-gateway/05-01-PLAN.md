From switchboard/admin/auth.py (COPY the pattern exactly for require_customer):
```python
_bearer_scheme = HTTPBearer(scheme_name="OperatorJWT", description="Operator JWT token (HS256)")

async def require_operator(
    credentials: Annotated[HTTPAuthorizationCredentials, Depends(_bearer_scheme)],
    settings: Annotated[Settings, Depends(get_settings)],
) -> dict:
    try:
        payload = jwt.decode(
            credentials.credentials,
            settings.operator_jwt_secret,
            algorithms=["HS256"],
            options={"require": ["exp", "iat", "sub"]},
            audience="switchboard-admin",
            issuer="switchboard",
        )
    except jwt.ExpiredSignatureError:
        raise HTTPException(status_code=401, detail="Token has expired",
                           headers={"WWW-Authenticate": "Bearer"}) from None
    except jwt.InvalidTokenError:
        raise HTTPException(status_code=401, detail="Could not validate credentials",
                           headers={"WWW-Authenticate": "Bearer"}) from None
    return payload
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Internet → Gateway | Customer-supplied JWT Bearer tokens; untrusted until validated |
| Gateway → Settings | CUSTOMER_JWT_SECRET env var; must satisfy 32-byte minimum at startup |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-5-01 | Spoofing | require_customer | mitigate | PyJWT `jwt.decode` with `algorithms=["HS256"]` and `audience="switchboard-gateway"` — rejects alg:none, wrong audience, expired tokens; `options={"require": ["exp","iat","sub"]}` enforces claim presence |
| T-5-02 | Tampering | Settings.customer_jwt_secret | mitigate | `@field_validator` enforces 32-byte minimum; empty string raises ValueError at startup — app cannot boot with weak secret |
| T-5-03 | Information Disclosure | 401 error responses | accept | Error messages are intentionally generic ("Token has expired" / "Could not validate credentials") — does not reveal secret value or signing algorithm choice |
| T-5-04 | Elevation of Privilege | Audience confusion attack | mitigate | `audience="switchboard-gateway"` in `jwt.decode`; operator tokens with `audience="switchboard-admin"` are rejected by `require_customer`; customer tokens with `audience="switchboard-gateway"` are rejected by `require_operator` |
</threat_model>

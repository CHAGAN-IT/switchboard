## Critical Gap: Phase 02 JWT Security Vulnerability

**Severity:** High (security)
**File:** `switchboard/config.py`

The `operator_jwt_secret` field validator checks `if v and len(v.encode()) < 32` — the `if v` guard means an empty string skips the length check entirely. PyJWT accepts an empty string as a valid HS256 signing key (with a warning). A misconfigured deployment without `OPERATOR_JWT_SECRET` set will accept attacker-forged tokens signed with the empty string.

**Fix:** Change validator to `if len(v.encode()) < 32` (remove the `if v` guard) so an empty or missing secret always fails validation.
